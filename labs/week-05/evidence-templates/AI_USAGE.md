# ENGSE203 LAB05 — AI / Resource Usage

| Tool / Resource | Purpose | Used portion | How I verified | My final decision |
|---|---|---|---|---|
| Gemini | ช่วยแก้ไขข้อผิดพลาด และวิเคราะห์โค้ดว่าใช้ทำอะไรบ้าง | ส่วนของโค้ดที่เกิดข้อผิดพลาด ลอจิกการทำงานของ Service Layer / Local Storage | นำแนวทางที่ได้มาทำความเข้าใจ รันทดสอบจริงบนหน้าเว็บเคลียร์ Local Storage และรันคำสั่ง npm run check เพื่อยืนยันว่าโค้ดทำงานถูกต้อง | นำคำอธิบายและแนวทางการแก้โค้ดมาปรับประยุกต์ใช้กับโปรเจกต์ด้วยตนเอง เพื่อให้ระบบทำงานได้สมบูรณ์ตรงตาม Requirement |
| Gemini | ช่วยอธิบายการทำงานของโค้ดส่วนที่ไม่เข้าใจ | คำอธิบายการทำงานของโค้ด (เช่น Service Layer, การจัดการ Local Storage) | นำคำอธิบายมาศึกษาเทียบกับ Source Code จริง และทดลองรันระบบบน Localhost เช่น ลองเคลียร์ข้อมูล หรือทำข้อมูลให้พัง เพื่อดูผลลัพธ์การทำงานว่าตรงกับที่อธิบายไหม | สรุปความเข้าใจที่ได้ด้วยตนเอง และนำมาประยุกต์ใช้ในการแก้ไขโปรเจกต์ให้สมบูรณ์จนผ่านการทดสอบ |
