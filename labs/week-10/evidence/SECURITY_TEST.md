## ผลการทดสอบ SQL Injection

### ① เงื่อนไขที่เป็นจริงเสมอ
**ยิง** `GET /api/requests?status=x' OR '1'='1`
**ผลที่ได้** `[]` (0 รายการ) ✓ ถูกป้องกัน
**เพราะ** ใช้ parameterized query (`?`) — ค่าถูกตีความเป็นข้อความธรรมดา ไม่ใช่คำสั่ง SQL

### ② พยายามลบตาราง
**ยิง** `GET /api/requests?status='%3B DROP TABLE requests%3B --`
**ผลที่ได้** `[]` (0 รายการ) ✓ ถูกป้องกัน และตาราง `requests` ยังอยู่ปกติ
**เพราะ** ค่าที่รับเข้ามาจะถูกมองเป็นเพียง string ตัวหนึ่งในการค้นหาสถานะ

### ③ ต่อเงื่อนไขเพิ่ม
**ยิง** `GET /api/requests?status=pending'%20OR%20status='completed`
**ผลที่ได้** `[]` (0 รายการ) ✓ ถูกป้องกัน
**เพราะ** ใช้ parameterized query ทำให้ SQL มองข้ามการเชื่อมคำสั่ง
