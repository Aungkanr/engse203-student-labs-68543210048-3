# บันทึกการใช้งาน AI ช่วยเหลือในการทำโปรเจกต์ (AI_USED.md)

**เครื่องมือ AI ที่ใช้งาน:** Gemini  
**รหัสนักศึกษา:** 68543210048-3  

ในสัปดาห์นี้ ได้มีการใช้งาน AI เพื่อช่วยแก้ปัญหา (Troubleshooting) เป็นหลัก โดยเฉพาะปัญหาเกี่ยวกับการตั้งค่าเครื่องมือ VS Code Database Client, การวิเคราะห์ Error Message จากหน้าจอ, การจัดการไฟล์ใน Workspace, และช่วยในการจัดรูปแบบเอกสาร Markdown เพื่อส่งงาน โดยมีรายละเอียดการใช้งานดังนี้:

---

## ครั้งที่ 1 : การแก้ปัญหาเชื่อมต่อฐานข้อมูลไม่ได้ (Error: No tables found & ENOENT)

**ถามอะไร**
- ถ่ายรูปหน้าจอ Extension Database Client ส่งให้ AI ดู 2 รอบ 
- รอบแรก: ถามว่าทำไมแถบขวามือในโฟลเดอร์ Table ถึงไม่มีข้อมูล (ขึ้น No tables found) และไฟล์มีขนาด 0 B 
- รอบสอง: ถามสาเหตุที่เกิด Error ตัวแดง `connect ENOENT` ตอนที่พยายามกรอก Path ไฟล์

**AI ตอบว่าอย่างไร (สรุปสั้น)**
- วิเคราะห์จากภาพและชี้ให้เห็นว่า เลือกประเภทเซิร์ฟเวอร์ผิด (ไปเลือก MySQL แทนที่จะเป็น SQLite) 
- ชี้จุดผิดพลาดว่าใส่ File Path ผิดช่องและผิดรูปแบบ (เอาข้อความแสดงลำดับโฟลเดอร์ไปใส่แทนที่อยู่ไฟล์จริง) 
- บอกวิธีแก้ไขทีละสเต็ป ให้เปลี่ยนเป็น SQLite และกด Browse เลือกไฟล์ `campus.db` ตัวจริงในเครื่อง

**ใช้ส่วนไหน / แก้เองตรงไหน**
- ลบ Connection เก่าทิ้ง สร้างใหม่เป็น SQLite จนสามารถมองเห็นตารางใน Database ได้สำเร็จ

**เข้าใจสิ่งที่ AI อธิบายไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## ครั้งที่ 2 : ปัญหาความสับสนเรื่องไฟล์ชั่วคราวและการดูประวัติโค้ด

**ถามอะไร**
- ถาม AI ว่าทำไมอยู่ดีๆ ข้อมูลใน Query ถึงหายไป (หน้าจอไปโผล่ที่แท็บชื่อ `New_Query_...`) 
- ถามวิธีการดูประวัติการแก้โค้ดเพื่อเช็คว่าตัวเองเคยแก้อะไรไปบ้าง

**AI ตอบว่าอย่างไร (สรุปสั้น)**
- อธิบายกลไกของ Extension ว่ามันมีหน้าต่างแยกฝั่งซ้าย (ไฟล์จริง `queries.sql` ของเรา) กับฝั่งขวา (แท็บชั่วคราวที่ Extension สร้างให้) ข้อมูลไม่ได้หาย แต่เรากำลังดูผิดแท็บ
- อธิบายวิธีใช้เครื่องมือ Source Control (Git) ใน VS Code เพื่อดูการเปลี่ยนแปลงของโค้ดเทียบซ้าย-ขวา และวิธีเปิดดู Timeline ของไฟล์นั้นๆ

**ใช้ส่วนไหน / แก้เองตรงไหน**
- ปรับ Workflow การทำงานใหม่ พิมพ์และทดสอบโค้ดที่ฝั่งขวาก่อน พอมั่นใจแล้วค่อยก๊อปปี้กลับมาเซฟลงไฟล์ `queries.sql` ในฝั่งซ้ายเพื่อเตรียมส่งงาน

**เข้าใจสิ่งที่ AI อธิบายไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## ครั้งที่ 3 : การจัดรูปแบบเอกสารและรวบรวมไฟล์ (CP24, CP25)

**ถามอะไร**
- ส่งข้อมูลตาราง ผลการทดสอบ (Negative Testing) และเนื้อหาที่ทำเสร็จแล้วให้ AI 
- สั่งให้ AI นำข้อมูลทั้งหมดไปใส่ลงในโครงสร้างของไฟล์ `DATA_MODEL.md` ให้ถูกต้อง และขอให้ออกมาเป็นโค้ด Markdown ไฟล์เดียวรวมกันทั้งหมดเพื่อนำไปส่ง

**AI ตอบว่าอย่างไร (สรุปสั้น)**
- AI นำข้อมูลผลการรันทดสอบของผมจากไฟล์ `EVIDENCE.md` ไปจัดเรียงในหัวข้อที่ 7 ตามโครงสร้างเอกสาร
- สรุปรวมโค้ด Markdown ตั้งแต่หัวข้อ 1-7 เป็นไฟล์เดียว โดยลบคอมเมนต์ที่โจทย์ให้ไว้ออกให้ตามสั่ง

**ใช้ส่วนไหน / แก้เองตรงไหน**
- ก๊อปปี้โค้ด Markdown ที่ AI รวมให้ ไปวางทับในไฟล์ `DATA_MODEL.md` เพื่อส่งงาน (เนื้อหาและผลการทดสอบข้างในเป็นสิ่งที่ผมรันและทำเองทั้งหมด AI แค่ช่วยจัด Format)

**เข้าใจสิ่งที่ AI อธิบายไหม** ☑ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☐ ยังไม่เข้าใจ

## สรุปภาพรวมการทำงาน

- **ส่วนที่เขียนและวิเคราะห์เองทั้งหมด:**
  - การเขียนคำสั่ง SQL (SELECT, JOIN, WHERE, GROUP BY) เพื่อตอบโจทย์ 8 ข้อ
  - การรันคำสั่งทดสอบ Error Constraint ในฐานข้อมูลด้วยตัวเอง
  - การทำความเข้าใจโครงสร้างฐานข้อมูลและการวิเคราะห์ปัญหา Update Anomaly
- **ส่วนที่ AI ช่วยเหลือและให้คำแนะนำ:**
  - ช่วย Debug ปัญหาการตั้งค่าโปรแกรมและเครื่องมือ Database Client แบบ Step-by-step
  - ช่วยอธิบาย Error จากภาพหน้าจอให้เข้าใจง่ายขึ้น
  - ช่วยประหยัดเวลาในการจัดรูปแบบ (Formatting) เอกสาร Markdown ท้ายแล็บ
- **สิ่งที่ได้เรียนรู้และพัฒนาทักษะ:**
  - รู้วิธีอ่าน Error Message อย่างถูกต้อง (ENOENT, Cannot find path)
  - เข้าใจกลไกการแยกส่วนระหว่าง Workspace ของ VS Code กับการทำงานของ Extension

## คำรับรองการใช้งาน AI อย่างมีจริยธรรม

- [x] ไม่ส่ง Token, Password, Secret Key หรือข้อมูลส่วนบุคคลที่เป็นความลับจริงให้เครื่องมือ AI
- [x] ตรวจสอบโค้ด SQL, รันคำสั่งจริงบนฐานข้อมูล `campus.db` และตรวจสอบด้วยสคริปต์ตรวจงานด้วยตนเองทุกขั้นตอน
- [x] เข้าใจโครงสร้าง Schema, ความสัมพันธ์ของตาราง, คำสั่ง SQL Query ทุกข้อ และพร้อมอธิบายต่อผู้สอนในการสอบถามแบบสุ่ม
