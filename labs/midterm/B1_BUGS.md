## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | `components/RequestList.jsx : 7-8` | การใช้ `.map()` สร้างรายการ โค้ดไม่ได้ใส่ prop `key` ลงไป ทำให้ React ไม่สามารถแยกแยะและติดตามแต่ละรายการในหน้าจอได้ | เติม `key={request.id}` เข้าไปใน Component `RequestCard` ภายในวงเล็บของ `.map()` |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `pages/DashboardPage.jsx : 47` | โค้ดเดิมไปนับรวมสถานะ `completed` เข้ามาด้วย แทนที่จะนับเฉพาะ `pending` | เปลี่ยนค่าเปรียบเทียบในเงื่อนไขการกรองจาก `completed` เป็น `pending` |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | `pages/DashboardPage.jsx : 55` | ตัวแปร `filteredRequests` มีการใช้เครื่องหมาย `!==` ทำให้ระบบทำงานกลับด้าน (กรองเอาตัวที่ไม่เกี่ยวมาแสดง) | เปลี่ยนเครื่องหมายในเงื่อนไขจาก `!==` เป็น `===` |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage.jsx : 28` | `useEffect` ที่ใช้โหลดข้อมูลใส่ Dependency ไว้แค่ `reloadKey` แต่ไม่ได้ใส่ `requestId` พอ ID บน URL เปลี่ยน `useEffect` เลยไม่ทำงาน | เติม `requestId` เข้าไปใน Dependency Array เพื่อสั่งให้รันโค้ดใหม่ทุกครั้งที่ ID เปลี่ยน |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | `pages/DashboardPage.jsx : 65` | โค้ดเรียก `setRequests(requests)` ซึ่งเป็นการเอา State เก่าที่ยังไม่ได้ลบข้อมูลไปเซ็ตทับหน้าจออีกรอบ | เปลี่ยนไปใช้ตัวแปร `nextRequests` (ข้อมูลใหม่หลังลบ) ในการ `setRequests` |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | `pages/DashboardPage.jsx : 75` | ฟังก์ชัน `resetRequests` เป็นแบบ async ซึ่งคืนค่าเป็น Promise เสมอ แต่โค้ดเอาไปสั่งเรนเดอร์เลย React จึงเอา Promise ไปวาดหน้าจอจนพัง | ใส่ `await` นำหน้าฟังก์ชัน `resetRequests` เพื่อรอให้ดึงข้อมูลเสร็จก่อนนำไปใช้งาน |
